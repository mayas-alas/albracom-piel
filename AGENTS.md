# Reglas

- Landing estática: quién compra → necesidad → WhatsApp. Máximo tres acciones en el recorrido inicial.
- Tiendanube, decoración, checkout, app y datos clínicos fuera de alcance.
- El contacto se configura con WHATSAPP_PHONE fuera del código. No escribir el número real en archivos, pruebas o historial. El enlace público sí lo revela; no es un secreto del navegador.
- Identificación local anónima, no inferir nombre ni diagnóstico; sin trackers ni backend.
- No inventar productos, avales o beneficios médicos. Describir confort, no prevención/curación de heridas.
- Mantener documentación y dependencias mínimas. El Worker mantiene producción; GitHub Actions construye la imagen y publica también en Pages cuando está disponible, sin mover el dominio ni su firewall.
